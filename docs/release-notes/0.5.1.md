## Fixed

- `gac status` and `gac doctor` no longer report an expired session as fine when it can't
  actually be refreshed. Both now try the refresh, as the next AWS command would: a session that
  still works shows as logged in, and one whose sign-in has ended shows the service's error and
  `gac login` as the fix. `gac status --json` adds `refreshError`. `gac whoami` still reads only
  local files, so it stays fast enough for a shell prompt. (#47)
- The Scoop install test in the release workflow installs the local manifest correctly. (#46)

Nothing to do when upgrading.
