## Fixed

- Listing accounts (`gac list`, `gac sync`, and picking a role when the listing isn't cached)
  no longer stalls when Identity Center throttles it. A throttled listing used to wait about 20 s
  whatever its size; it now stays close to the rate the portal allows. Under sustained throttling, large listings could fail outright once the AWS
  SDK's retry budget ran out; throttled retries no longer draw on it, so they finish. (#64)
- `gac` with no arguments prints its help to stdout and exits 0, as `gac -h` does. It printed to
  stderr and exited with code 2, which made winget's validation reject the package. Anything else
  without a subcommand is still a usage error with code 2. (#65)

## Documentation

- The README answers whether `gac` works with Okta, Microsoft Entra ID or Google Workspace: it
  does when the provider is IAM Identity Center's identity source. (#49)

Nothing to do when upgrading.
